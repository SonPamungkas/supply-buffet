# Highlight: Supply Run
- **Adaptive (Naval & Ground):** When a ship or ground vehicle spent its munitions, Supply Buffet automatically coordinates a supply run using Ibis and Tarantula. From land airbase or Naval Airbase (bypassing restriction such as the lack of AI or Airframes in Reserve)
- **Accurate:** Assigns exactly the right payload — Munitions Pallets and Containers for ground targets, and Naval Pallets/Containers for ships — completely bypassing vanilla RNG or hardcoded limits.
